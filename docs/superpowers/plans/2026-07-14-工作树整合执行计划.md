# 工作树整合执行计划

> **执行约束：**本计划按任务逐项执行。每个任务完成后必须验证，任何验证失败都停止后续清理操作。

**目标：**将交付工作树的已验证代码整合到桌面主工作树，保留桌面未提交修改的可恢复副本，完成代码验证后移除冗余工作树。

**架构：**桌面主工作树保留为最终工作树。先将其业务未提交修改保存为命名贮藏，再把交付工作树最新提交合并到桌面分支。交付工作树已包含其他候选工作树的提交历史，因此不分别合并祖先工作树。桌面贮藏不自动恢复；仅在逐项对照证明包含交付版本未覆盖的有效行为时才提取最小改动。

**技术栈：**版本控制、后端测试、前端工具测试、远程调用代码生成、前端浏览器构建。

## 任务一：记录整合前状态并保护桌面修改

**文件：**
- 新增：版本控制中的命名贮藏记录
- 不修改：任何业务源文件

- [ ] **步骤一：记录当前桌面分支、提交、状态和工作树列表。**

```powershell
git status --short --branch
git log -1 --oneline
git worktree list --porcelain
```

预期：桌面工作树包含已提交的设计与执行计划文档，以及待保护的业务未提交修改。

- [ ] **步骤二：创建包含未跟踪文件的命名贮藏。**

```powershell
git stash push --include-untracked --message "桌面整合前业务修改备份"
```

预期：桌面工作树变为干净状态；贮藏中保留十八个已修改文件和十个未跟踪文件。

- [ ] **步骤三：确认贮藏存在且桌面工作树已干净。**

```powershell
git stash list
git status --short --branch
```

预期：贮藏列表顶部存在“桌面整合前业务修改备份”，状态输出不含业务文件。

## 任务二：合并交付工作树基线

**文件：**
- 修改：由交付工作树引入的安全、行程、智能体、配置和前端文件
- 不恢复：任务一保存的桌面业务贮藏

- [ ] **步骤一：确认交付提交是桌面已提交业务基线的后继。**

```powershell
git merge-base --is-ancestor 91a2a58 e1cf409
```

预期：命令成功结束。

- [ ] **步骤二：将交付提交合并到桌面分支。**

```powershell
git merge --no-ff e1cf409 -m "merge: 整合交付工作树"
```

预期：创建一个只包含交付工作树已提交改动的合并提交；设计与执行计划文档保持存在。

- [ ] **步骤三：确认工作树干净且合并提交存在。**

```powershell
git status --short --branch
git log --oneline -3
```

预期：除命名贮藏外，桌面工作树不含未提交业务改动；最新历史包含整合提交。

- 测试：前端全部工具测试
- 验证：接口定义与生成代码、浏览器构建

- [ ] **步骤二：执行前端工具测试。**

预期：全部前端工具测试通过，包含运行时接口地址测试。

```powershell

```

预期：构建成功，生成文件位于已忽略的构建目录。

- [ ] **步骤四：执行接口定义与生成代码编译校验。**


- [ ] **步骤五：复核安全与整合重点。**


预期：登录失败限流、令牌刷新、行程更新、智能体远程流式相关测试均通过。

## 任务四：审查并保留桌面贮藏

**文件：**
- 保留：桌面整合前业务修改备份贮藏
- 不恢复：与交付工作树重复或较旧的实现

预期：明确显示桌面旧修改与当前整合代码的差异。

预期：不直接恢复旧文件；贮藏继续保留，作为可追溯恢复点。

## 任务五：删除冗余工作树

**前提：**任务三全部通过，任务四确认不需要恢复桌面贮藏内容。

- [ ] **步骤一：确认待删除工作树均干净。**

```powershell
git -C C:\tmp\Travel-Assistant-delivery status --short
git -C C:\tmp\Travel-Assistant-merge-stabilization status --short
git -C C:\tmp\Travel-Assistant-phase1 status --short
git -C C:\tmp\Travel-Assistant-phase1-v2 status --short
```

预期：所有待删除工作树无未提交或未跟踪文件。

- [ ] **步骤二：删除已包含于整合历史中的冗余工作树。**

```powershell
git worktree remove C:\tmp\Travel-Assistant-delivery
git worktree remove C:\tmp\Travel-Assistant-merge-stabilization
git worktree remove C:\tmp\Travel-Assistant-phase1
git worktree remove C:\tmp\Travel-Assistant-phase1-v2
```

预期：四个冗余工作树目录消失；桌面工作树仍存在。

- [ ] **步骤三：清理失效记录并最终确认。**

```powershell
git worktree prune
git worktree list --porcelain
git status --short --branch
```

预期：工作树列表只保留桌面工作树；桌面分支状态干净；命名贮藏仍存在。

## 提交边界

1. 设计与执行计划文档单独提交。
2. 交付工作树通过合并提交进入桌面主工作树。
3. 不将桌面整合前贮藏作为新的功能提交自动恢复。
4. 若未来确认贮藏包含独有有效行为，必须以单独测试、单独提交迁入。
