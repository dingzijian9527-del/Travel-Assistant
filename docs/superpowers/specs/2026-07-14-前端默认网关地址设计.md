# 前端默认网关地址设计

## 一、目标

让本地前端在未设置任何构建环境变量时，默认将接口请求发送到本机网关地址，并在收到网页内容或其他非接口响应时显示准确错误提示。

## 二、根因

前端运行时配置在未设置构建变量时返回空字符串。登录页面据此发送相对路径请求，浏览器把请求发给前端开发服务器而非后端网关。开发服务器返回网页内容后，登录页面按结构化接口响应解析失败，并误显示网关不可用。

## 三、设计

1. 前端运行时配置直接使用本机网关地址作为默认接口基础地址，不依赖构建环境变量。
2. 保留地址规范化函数，保证末尾斜杠不会导致重复分隔符。
3. 新增统一的接口响应解析函数：仅接受结构化接口响应；收到网页内容或其他非结构化内容时返回“网关返回了非接口数据，请检查网关地址”。
4. 登录与注册后的自动登录复用该解析函数，网络连接异常仍显示“网关服务暂不可用”。

## 四、修改范围

```text
front/src/utils/runtime.js
front/src/utils/runtime.test.mjs
front/src/pages/login/index.vue
front/src/pages/register/index.vue
```

## 五、验证要求

1. 默认接口基础地址为本机网关地址。
2. 地址规范化规则保持不变。
3. 非结构化响应会产生准确错误信息。
4. 登录页面使用默认网关地址构造请求。
5. 前端工具测试和浏览器构建通过。
