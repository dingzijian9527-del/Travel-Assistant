# Travel Assistant 前端

本目录为 Travel Assistant 旅行助手的 UniApp 前端工程。

## 技术栈

- UniApp
- Vue
- 移动端优先设计

## 页面

- `pages/index/index.vue`：首页，包含目的地搜索、出发日期、人数筛选、AI 行程生成入口、热门目的地和推荐行程。
- `pages/trip/index.vue`：行程页占位。
- `pages/discover/index.vue`：发现页占位。
- `pages/profile/index.vue`：我的页占位。

## 设计来源

界面风格由 Stitch MCP 生成设计方向后落地，主色为蓝绿色，强调清爽、现代、可用的信息密度。
